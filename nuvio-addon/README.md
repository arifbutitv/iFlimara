# ArifButi VIP لتطبيق Nuvio

إضافة **ArifButi VIP** ببروتوكول Stremio: قائمة **TV Live** أولًا، وست قوائم للأفلام والمسلسلات، مع البحث والبيانات والصور والحلقات وتشغيل HLS وMP4 وDASH بحسب المصدر. تعمل مع Nuvio والعملاء المتوافقين مع البروتوكول.

## تثبيت الخدمة المنشورة

في Nuvio افتح **الإعدادات ← Addons ← Add Addon** والصق:

```text
https://ifilmar-nuvio.onrender.com/manifest.json
```

ثبّت **ArifButi VIP**. لتحديث نسخة قديمة وإظهار القوائم الجديدة، احذف الإضافة وأعد تثبيتها بالرابط نفسه. البحث مفعل في القوائم العشر، وتُجمع حلقات ShiaTube حسب عنوان المسلسل.

### TV Live — الإصدار 1.4.0

انشر الإصدار **1.4.0** في Render مرة واحدة، ثم أعد تثبيت الإضافة لإظهار **TV Live** في المقدمة. القنوات بالترتيب: [iFilm](https://ar.ifilmtv.ir/Home/Live)، [Al-Kawthar](https://www.alkawthartv.ir/live)، [Al-Maaref](https://almaaref.ch/البث-المباشر-6/). تستخدم القائمة نوع `tv` ومعرّفات قنوات ثابتة وتدعم البحث بالعربية والإنجليزية. يُجلب البث من المشغلات الرسمية؛ تُستبعد جودات آي فيلم غير المتاحة، وتُجدد روابط الكوثر المؤقتة عند التشغيل مع تخزين مؤقت لمدة 30 ثانية. ينتقل الفيديو من مزوّد البث مباشرة إلى المشاهد، ولا يُمرّر عبر Render.

اختبار البث الحي: `node scripts/live-smoke.js`، ويختبر القائمة والبيانات وملفات HLS وجزءًا صغيرًا من الفيديو لكل قناة.

تحتاج خدمة Render الحالية إلى نشر الإصدار **1.3.0** أو أحدث مرة واحدة لإضافة الكوثر. قوائم الكوثر وحلقاته تُقرأ من الموقع مباشرة، مع تخزين مؤقت لمدة 10 دقائق؛ لا تحتاج تشغيل مُحدّث ShiaTube أو إعادة نشر Render عند إضافة حلقة جديدة. يشمل البحث جميع صفحات فئة الأفلام أو المسلسلات، وتُعرض الحلقات بترتيب تصاعدي دون استخدام إعلان المسلسل كحلقة. يدعم التشغيل فيديو الكوثر المباشر ومشغل نماشا المضمّن حين يوفر رابط فيديو، وتعتمد الإتاحة على المصدر.

## النشر والتثبيت

يلزم خادم ويب يعمل باستمرار؛ رابط GitHub الخام ليس رابط تثبيت لهذه الإضافة.

1. أنشئ حساب Render واربط GitHub.
2. افتح [نشر إعدادات المستودع على Render](https://render.com/deploy?repo=https://github.com/arifbutitv/iFlimara) وراجع الخدمة ثم أنشئها. إعدادات النشر في `render.yaml` بجذر المستودع. تحقق من الخطة والتكلفة التي يعرضها Render قبل الموافقة؛ توفر الخطط يتغير.
3. بعد نجاح النشر انسخ عنوان الخدمة وأضف `/manifest.json` في نهايته.
4. في Nuvio: الإعدادات ← Addons ← Add Addon، الصق الرابط وثبّت الإضافة.

مثال للشكل فقط، وليس عنوان خدمة منشورة:

```text
https://YOUR-SERVICE.onrender.com/manifest.json
```

الخدمة المجانية قد تتوقف عند الخمول، فتتأخر أول استجابة. لا توجد مفاتيح API أو متغيرات سرية مطلوبة.

## التشغيل على خادم Node.js

يتطلب Node.js 22 أو أحدث:

```sh
cd nuvio-addon
npm ci
npm test
npm start
```

العنوان المحلي: `http://localhost:7000/manifest.json`. على جهاز آخر في شبكتك استخدم عنوان IP الخاص بالخادم بدلاً من localhost. للوصول من الإنترنت انشر الخدمة بعنوان HTTPS.

يمكن أيضاً بناء صورة Docker من هذا المجلد؛ المنفذ الافتراضي 7000 ويدعم متغير `PORT`.

## الواجهات والاختبار

- `/manifest.json`: تعريف الإضافة.
- `/catalog/series/ifilmar-series.json`: المسلسلات.
- `/catalog/movie/ifilmar-movie.json`: الأفلام.
- `/catalog/series/ifilmar-series/search=QUERY.json`: البحث؛ يجب ترميز QUERY بصيغة URL.
- `/meta/series/ifilmar:series:74467.json`: التفاصيل والحلقات.
- `/stream/series/ifilmar:series:74467:1:1.json`: مصادر الحلقة الأولى.
- `/stream/movie/ifilmar:movie:74595.json`: فيديو الفيلم.
- `/health`: فحص عمل الخدمة.

`npm test` لا يتصل بالشبكة ويفحص التصفح والبحث والحلقات والروابط والاستجابات. `npm run test:live` يفحص الموقع الحقيقي والوسائط بطلب أجزاء صغيرة دون تنزيل الفيديو كاملاً.

نتائج آي فيلم تُخزن مؤقتاً لدقيقتين. ترقيم الصفحات يتوافق مع طلبات العميل ذات 100 عنصر. يتصل Nuvio بخادم الوسائط مباشرة لمحتوى آي فيلم.

يُحل فيديو ShiaTube عبر مسار `/shiatube/play/VIDEO_ID.mp4`. المصادر المباشرة تعيد توجيه المشغل إلى خادم الفيديو، بينما تمر ملفات OK.ru عبر خادم الإضافة مع دعم Range لأن روابطها مرتبطة بعنوان IP الذي استخرجها. تشغيل OK.ru يستهلك نقل بيانات الاستضافة، ولا يقبل المسار عناوين فيديو عشوائية من المستخدم.

فهرس ShiaTube محفوظ في `data/shiatube.json`، ومراجع المشغلات الثابتة في `data/shiatube-sources.json`. يستخدم التشغيل المراجع المحفوظة لأن ShiaTube قد يعيد 403 لطلبات الاستضافة. روابط OK.ru المؤقتة لا تُحفظ؛ تستخرجها الخدمة عند التشغيل من مرجع المشغل الثابت.

لتحديث الأرشيف ومراجع التشغيل يدويًا من اتصال يسمح بقراءة الموقع:

```sh
node scripts/sync-shiatube.js
node scripts/index-shiatube-sources.js
```

الفهرسة تتم بوتيرة محدودة وتدعم الاستكمال بعد انقطاعها. يقارن فهرس المصادر عينات من بداية ووسط ونهاية المسلسل؛ عندما تنشر عينتان على الأقل مسار VOD المرقم نفسه دون اختلاف في جذر المسار، يُستخدم ذلك المسار لبقية الحلقات. بخلاف ذلك يُقرأ مشغل كل حلقة على حدة. عند تعديل الفهرسين يدويًا، شغّل أيضًا `node scripts/write-shiatube-state.js` وارفع الملفات الثلاثة معًا.

### التحديث التلقائي

أظهرت الاختبارات أن ShiaTube يعيد 403 من خوادم Render وGitHub؛ لذلك الجدولة السحابية متوقفة. يُستخدم مُحدّث محلي على Windows كل 6 ساعات عند تشغيل جهاز المالك وتسجيل الدخول، دون الحاجة إلى تشغيل Codex. يقرأ أحدث الصفحات حتى يصل إلى فيديو معروف، ويحفظ المحتوى الجديد فقط، ثم يستخرج مراجع المشغلات ويجري الاختبارات. عند النجاح يدفع تغييرات البيانات إلى المستودع؛ لا تُنشأ عملية حفظ جديدة إن لم تتغير البيانات.

لتشغيل تحديث يدوي من نسخة المستودع المحلية المعدة للمُحدّث:

```sh
node nuvio-addon/scripts/run-local-update.js
```

يتطلب Node.js وGit وتسجيل دخول GitHub القادر على الدفع إلى المستودع. يسجل النتائج في `.local-update.log`، ويمنع تشغيل نسختين بالتزامن. تستخدم الجدولة حساب المستخدم الحالي دون حفظ كلمة مرور جديدة. إذا كان الجهاز مطفأً أو غير متصل، يتأجل التحديث إلى تشغيل المهمة لاحقًا. لا حاجة إلى نشر Render يدويًا بعد كل تحديث بيانات.

من الإصدار **1.2.0** تتحقق خدمة الإضافة من ملف حالة صغير في GitHub عند التصفح، مرة كل 10 دقائق كحد أقصى. إذا تغيرت المراجعة تنزل الفهرسين، وتتحقق من تطابق بصمتهما واكتمال المراجع، ثم تحدّث المحتوى داخل الخدمة العاملة. لا تحتاج إعادة نشر Render عند كل حلقة جديدة؛ تحتاج نشر هذا الإصدار مرة واحدة لتفعيل الميزة.

إذا فشل الفحص المحلي فلا تُنشر بيانات ناقصة. وإذا تعذر تحميل الفهرس المنشور من GitHub تبقى النسخة الحالية تعمل. تتطلب الميزة بقاء ملفات البيانات قابلة للقراءة من GitHub. يوضح `/health` مراجعة المحتوى المحملة وتاريخها وعدد الفيديوهات. مسار GitHub اليدوي متاح للفحص، لكنه ليس مصدر التحديث التلقائي الحالي.

الفيديوهات التي يعلن الموقع أنها قيد المراجعة لا تُعرض لها مصادر تشغيل. إذا كان مصدر الفيديو الوحيد رابط YouTube، يظهر كرابط خارجي باسم واضح.

`node scripts/shiatube-smoke.js` يفحص القائمتين والبحث وتشغيل عينة من كل نوع عبر واجهات HTTP. يمكن ضبط `ADDON_URL` لفحص الخدمة المنشورة.

## حدود المصدر

بعض صفحات الأفلام تحتوي إعلاناً فقط أو لا تحتوي فيديو؛ تعيد الإضافة الفيديو المنشور فقط، أو قائمة مصادر فارغة عند غيابه. لا تحول الإعلان إلى فيلم كامل. تواريخ الحلقات غير المنشورة في المصدر لا يتم اختلاقها. قد تمنع المنطقة الجغرافية أو أعطال المصدر بعض الروابط.

الإضافة مستقلة عن Nuvio وآي فيلم. حقوق المحتوى لأصحابه.

## الإصدار 1.5.0

اسم الإضافة **ArifButi VIP** مع الاحتفاظ بمعرّف الإضافة ورابط تثبيتها. قائمة TV Live أولًا وتضم بالترتيب: آي فيلم، الكوثر، المعارف، الإيمان، النعيم، الجوادين، الغدير. أضيفت القنوات الأربع من صفحاتها الرسمية في cpweb.ettehadlive.com. تستخرج الإضافة ملفات HLS عند التشغيل، والفيديو مباشر من مزوّد البث دون وسيط Render.

الشعارات الأصلية ملك للقنوات؛ حُفظت نسخها داخل `assets/live` على بطاقات PNG مربعة 512×512 مع الحفاظ على النسب وحواف آمنة، لمنع قصّ الصور في Nuvio. يلزم نشر الإصدار 1.5.0 في Render ثم إعادة تثبيت الإضافة بالرابط نفسه لتحديث الاسم والقنوات والصور.

## الإصدار 1.6.0 — جدول البث iFilm

قائمة مستقلة بعد TV Live تعرض برامج الأسبوع المتاح في موقع آي فيلم، مرتبة باليوم والساعة مع الصور والوصف والبحث. المواعيد بتوقيت مكة المكرمة والبحرين (UTC+3)، بما يشمل البرامج عند منتصف الليل. تميّز البيانات الموعد الحالي والقادم عند توفر موعد البرنامج التالي. التشغيل من عناصر الجدول يفتح البث الحي للقناة؛ يمكن الاطلاع على أوقات البرامج السابقة والقادمة في التفاصيل.

تُجلب البيانات من الموقع تلقائيًا عند التصفح، مع تخزين مؤقت لمدة 5 دقائق. لا يحتاج تحديث الجدول تشغيل مُحدّث الجهاز أو إعادة نشر Render؛ انشر الإصدار 1.6.0 مرة واحدة وأعد تثبيت الإضافة لإظهار القائمة. اختبار الاتصال الفعلي: node scripts/schedule-smoke.js.

## الإصدار 1.6.1

تبدأ قائمة جدول البث iFilm بالبرنامج الجاري ثم البرامج القادمة، وتُخفى المواعيد المنتهية من التصفح والبحث قبل تقسيم الصفحات. يُعاد احتساب ذلك عند كل طلب باستخدام الوقت الحالي حتى أثناء التخزين المؤقت للجدول.

## الإصدار 1.7.0 — برامج آي فيلم والكوثر

أضيفت قائمتا آي فيلم — البرامج والكوثر — البرامج، مع البحث العربي وصفحات البرامج وحلقاتها وروابط تشغيلها. ترتيب القوائم: TV Live، جدول البث iFilm، آي فيلم (المسلسلات، الأفلام، البرامج)، الكوثر (المسلسلات، الأفلام، البرامج)، ShiaTube (المسلسلات، الأفلام). تبقى الأسماء ومعرّفات القوائم السابقة كما هي.

تُقرأ قوائم البرامج وحلقاتها من الموقعين مع تخزين مؤقت 10 دقائق دون تشغيل محدّث الجهاز. تعرض برامج الكوثر الحلقات الموجودة في قسم الحلقات بصفحة البرنامج، بما فيها الحلقات ذات العناوين والتواريخ دون أرقام، مع استبعاد قسم الكليبات. لا تتوفر حلقات لبعض برامج آي فيلم في المصدر؛ تبقى صفحة البرنامج معروضة دون إنشاء روابط فيديو غير موجودة.

لتفعيل القائمتين وترتيبهما انشر الإصدار 1.7.0 في Render وأعد تثبيت الإضافة بالرابط نفسه. اختبار المصدرين الفعلي: node scripts/programs-smoke.js.
